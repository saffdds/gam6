# 🚗 Gam6 Version 4.0

Un coinvolgente gioco arcade di guida sviluppato in Python utilizzando la libreria Pygame. Schiva gli ostacoli in arrivo, aumenta il tuo punteggio e batti il record personale scegliendo tra diversi livelli di difficoltà!

---

## ✨ Caratteristiche Principali

- **Menù Principale Intuitivo:** Interfaccia grafica completa con opzioni per giocare, leggere le istruzioni o uscire.
- **Selettore della Difficoltà:** Scegli tra tre livelli (*Facile*, *Media*, *Difficile*) che modificano la velocità iniziale e la frequenza di comparsa degli ostacoli.
- **Progressione Dinamica:** La velocità del gioco aumenta man mano che accumuli punti.
- **Sistema di Punteggio & High Score:** Tiene traccia del punteggio della partita corrente e del record massimo raggiunto.
- **Pronto all'uso (.exe):** Giocabile direttamente senza bisogno di installare Python o librerie aggiuntive.

---

## 🎮 Come Giocare

1. Avvia l'eseguibile del gioco.
2. Dal menù principale, clicca su **"Gioca"**.
3. Seleziona il livello di difficoltà desiderato (*Facile*, *Media* o *Difficile*).
4. Usa i tasti **Freccia Sinistra** $\leftarrow$ e **Freccia Destra** $\rightarrow$ per muovere la tua auto ed evitare i blocchi rossi.
5. Cerca di sopravvivere il più a lungo possibile per stabilire il record!

## 🚀 Download & Installazione

Poiché il gioco è già stato compilato in un file eseguibile, **non è necessario installare Python o Pygame sul tuo computer**.

1. Vai alla sezione **[Releases](../../releases)** del repository.
2. Scarica l'ultima versione disponibile (`.exe`).
3. Avvia l'applicazione e divertiti!
